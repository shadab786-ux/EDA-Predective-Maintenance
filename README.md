<h1>EDA Predective Maintenance <h1>
<h2>Project Overview</h2>
<p>Unplanned equipment failure in manufacturing leads to costly downtime, emergency repairs, and operational delays. This project performs an end-to-end Exploratory Data Analysis (EDA) on industrial sensor data to identify key operating conditions, risk factors, and failure modes preceding machine failure before deploying predictive machine learning models.</p>
<h3>Project Workflow</h3>
<p>Business Understanding → Data Audit → Cleaning → Feature Engineering → Univariate EDA → Outlier Analysis → Bivariate/Multivariate Analysis → Statistical Tests → Failure Diagnostics → Actionable Recommendations</p>
<h2>Key Business Objectives</h2>
<p>Establish baseline machine failure rates across product types (L, M, H).
  <br>
Analyze critical operating variables (Temperature, Rotational Speed, Torque, Tool Wear) and their relationship to failures.
   <br>
Engineer domain-specific features (Thermal Gap, Mechanical Power, Wear-Load Index) to capture physical strain on machinery.
   <br>
Diagnose specific failure mechanisms:
   <br>
TWF: Tool Wear Failure
   <br>
HDF: Heat Dissipation Failure
   <br>
PWF: Power Failure
   <br>
OSF: Overstrain Failure
   <br>
RNF: Random Failure
   <br>
Provide actionable maintenance recommendations for plant engineers.</p>
